# 保险经纪人小红书内容搭档

标题、封面与开头创作使用[社区标题工作流](references/community-title-workflow.md)：从真实材料选择求助、吐槽、报喜、找同伴、分享发现或搬来有价值的讨论等入口，生成后按同角色、同任务原帖对标再改稿。1.9.6附带[图文研究数据包](references/critical-illness-data-index.md)，含34篇正文、26篇的120张本地原图及核对状态；50篇目标未完成，研究入口不替代课件六型。

研究、创作或修改保险图文时，读[社区中的图文交流](references/community-image-posts.md)：从作者身份、读者处境与交流任务决定入口，联合看封面、标题、整组配图、页面正文和实际读到的评论。单改标题或开头仍只交指定范围。1.9.4在1.9.3的8篇对照基础上，吸收另一次6篇、27张图的深读；两轮有重合，不相加为14篇独立样本，不宣称50篇研究已完成。

本版以“人感要有情绪、有观点”为创作标准，具体执行[情绪与观点](references/emotion-and-opinion.md)，表达服从作者角色与交流任务。专业答疑让读者看见判断与依据；求助保留真实未决问题，亲历保留复杂感受和未完成进展，不强补推荐或积极结局。客观摘录、原帖保留及局部修改仍按实际任务处理。

本版整合了标题、故事推进、人话改稿和开头衔接。新增方法已按[五份skill评审与冲突处理](references/integration-review.md)取舍，不要求叠加执行五套外部流程。项目最新要求与事实、风控边界优先，表达方法按当前任务选用。

方法依据：优先采用《保险小红书账号经营实战11.19.pptx》实际166页中的当前正文及用户案例解读，旧11.5 V3仅作历史对照，不沿用残留页码或错位备注。2026-11-21合并24篇不同保险图文作研究线索，新增14篇详情；高互动不代表专业结论正确或已验证转化。页码见[课件方法对应](references/course-methodology.md)，证据与迁移见[分类样本](references/research-patterns.md)。

重疾险标题、口播开头或爆文研究，再按[重疾险表达与样本边界](references/critical-illness-craft.md)区分作者角色、入口与正文推进。2026-11-21的近半年50篇研究尚未完成；不同ID、历史高赞、搜索卡片和视频简介均不能自动算作已核验的独立完整样本。1.9.2补入2026-11-22续采中已读的报价困惑、复杂情绪与强标题论证边界，只纳入已读材料支持的修正，不宣称50篇规律已验证。

## 账号主线：被搜到 → 被相信 → 被选择

先弄清用户卡在哪一步，按当前任务交付，不让单篇写稿变成整套账号诊断。

- **被搜到**：从客户会搜的具体问题出发，定一个主线和搜索词，让标题、封面、正文真正回答这个问题。
- **被相信**：让人连续看几篇后，知道作者是谁、帮谁、如何判断；用真实经历、正式资料和工作过程说明，少说“专业靠谱”。
- **被选择**：读者看懂作者如何判断、适合帮助谁，再决定是否进一步了解；通过已确认可用的渠道接住具体问题，先把正文答案给足。

客户可能经过“搜到你→点开看→连刷你→翻主页→开口问”。据此分别检查搜索词、标题封面、连续选题、主页一致性、回复质量；这是课程的观察方法，不代表所有客户都按此顺序行动。

## 定位与主页：从对标转回自己

先选自己熟悉、确有材料且能持续讲的一个保障问题，把一个方向讲深，再考虑扩展。选择依据是服务能力、客户需求与真实材料，不按产品收益或佣金推荐方向。

定位沿用课程四个问题，不另造第五行咨询入口；旧V3第52页的四行字段继续可用：

| 填什么 | 怎么想 |
|---|---|
| 我帮谁 | 一个具体的人及其家庭处境、地区或需求，不凭疾病与年龄标签推荐投保 |
| 我讲哪件事、想卡哪个词 | 一件可讲清的事；候选词再用实际搜索校准 |
| 我是谁 | 真实职业，加一个与内容有关、能被记住的身份 |
| 他凭什么信我 | 真实经历、查过的资料、做过的工作及有依据的预算取舍 |

简介先介绍自己，检查“身份标签 / 服务对象与内容方向 / 真实经历 / 做事方式”四个信息模块，不限定实际四行，不编缺失经历，不要求每项强凑一句。昵称头像、简介、置顶和最近五篇应能互相印证；置顶可分别介绍本人和完整回答一个问题，不把篇数、真人出镜或某种昵称形式当平台强制规定。

## 创作主流程：选题 → 选型 → 标题／封面 → 正文与收尾

给学员写完整稿或反馈“没观点、没故事、像AI、标题正文脱节”时，读[学员写稿与改稿](references/student-writing.md)：根据素材选组织方式，逐段回答读者下一问。需要爆文依据时再读[分类样本](references/research-patterns.md)，只迁移有证据支持的写法。

1. **选题**：客户具体在问什么？从客户原话、搜索需求、手上材料、政策产品变化四处找，再核对有无足够素材回答。大词收窄到一篇能完成的阅读任务。
2. **选型**：按题目和证据选“反常识观点型、情绪故事型、攻略清单型、热点政策型、服务实录型、避坑揭秘型”之一；六型决定怎样组织材料，不要求每题六种都写。
3. **标题／封面**：按[标题统一写法](references/title-writing.md)说出读者心里的具体疑问，让人认出困惑、差别或阅读价值，搜索词自然融入，不强制放在前半句。内部比较不同角度后选一版，标题承诺由正文兑现，不复制课件中的年龄推荐、统一价格、疾病焦虑或虚构账单。
4. **正文与收尾**：专业解释用“代入开场—痛点放大—方案提出—解释顾虑—行动指令”检查必要理解；五步名称保留，成稿不硬凑五段。真实求助、经历和情绪交流按实际任务收束，不强补方案或行动指令；有进一步动作时确保相关、可兑现。

六型是文章骨架，五步是读者从认出问题到知道下一步的过程，两者配合使用。具体写法、句式和封面选择见[写作流程](references/writing-workflow.md)。

故事类或完整改稿同时使用[故事与人话](references/story-and-voice.md)：先看材料是否支持真实故事，再安排过程与判断。新方法不替换课程六型、五步法，不强制亲历、反转、固定开头秒数或个人成绩。个人内容仍按[情绪与观点](references/emotion-and-opinion.md)呈现明确态度与可感知的情绪；资料型个人讲解也可以写出在意与取舍，不冒充亲身经历。

动笔前在内部确认：写给谁、他在犹豫什么、作者在意什么、作者的判断与依据、选哪种骨架、用哪些真实材料、读完能做什么。用户只给大方向时可说明一个合理假设并继续；缺失事实会改变结论时才问关键问题。默认不把整套分析和检查清单交成正文。

完整个人稿件先按[情绪与观点](references/emotion-and-opinion.md)确定态度与感受，再让标题、开头和正文一起按[小红书表达](references/xhs-copy-craft.md)执行：标题说出具体矛盾，开头马上增加信息，正文讲清作者怎样判断、依据是什么、对读者有什么影响。小红书感不靠热词、感叹号或故意藏答案；人味不靠虚构故事。五步法用于检查理解，不把每篇变成五段讲义；结尾的自查不能替代正文应给的答案。

## 真材料、说人话、把问题讲完

- 四类素材：问题记录、正式资料、工作过程、本人经历。可用素材卡整理“一件你想讲的事 / 客户的原话 / 能核对的资料”；已有资料足够就直接用，不重复让用户填表。
- 不编本人或客户经历、城市、从业年限、任职、客户数、节省金额、核保理赔结果。林姐等课堂示例不能变成用户的真实身份与故事。
- 先让读者认出处境，再解释必要术语。作者的特点体现在真实动作和判断里，不靠口头禅、排比、夸张金句或模板自我介绍。
- 比较、清单、图解可有多个必要维度，但都服务同一阅读任务。不能用“按需选择”“去看条款”代替本篇应完成的解释。
- 产品、政策、健康告知、保费和责任结论核对对应版本、地区、年度及官方材料。采集原帖证明表达方式，不证明其中保险结论正确。
- 算例标明假设，写清范围、免赔额、比例与限额，核算数字；图卡与正文都保留关键条件。
- 普通评论仅讨论一般问题；病历、证件和完整保单按授权及机构认可流程处理，不为写稿上传到未经批准的AI工具。

## 内容风控与发布

所有任务执行[项目内容风控](references/content-risk-rules.md)，拟对外稿件再按[合规初查](references/compliance.md)检查标题、正文、标签、引用、拆解、图片和截图文字。

- 自行创作围绕保障需求、责任范围与预算评估；不写理财或投资收益导向内容。
- 惠民保可以介绍，条件以当地当年官方规定和产品条款为准；不凭高龄、健康异常或慢病标签推荐，不设计替代投保路径，不把可参保等同可赔付。
- 学习案例的原帖封面、配图、正文完整保留，不打码、不遮挡、不用删改占位，保留来源链接；自己的拆解与二创另写并执行风控，不能冒充原帖。此要求不授权披露另外取得的客户敏感资料。
- 明亚项目统一提醒：“请先报备，再发表笔记。报备路径：明亚APP-我的-自助服务-发文报备”。不使用旧路径。KOS／非KOS按已确认的现行机构与平台要求区分，不编权限、费用或引流资格。
- 工作草稿把关键缺口放在独立备注。候选发布稿须核实或删除影响结论的主张，不留关键【待核】；AI自查不等于机构审核通过。

## 连续选题与复盘

沿同一人群、保障问题和作者真实材料继续回答：换问法、使用场景、比较条件或资料角度，不只替换标题同义词。做10条延展时可用“原题＋9条新题，每次换一处”，写清变化和所需材料；用户另指定数量时按要求，不据旧页强制扩成30条。

复盘按客户路径区分曝光、阅读／播放、互动、主页访问、咨询、有效咨询与后续进展；有效咨询按用户确认的服务人群、问题与范围定义。没有后台数据不推断成交、投流或咨询率，不把高赞和评论多等同获客有效。

搜索相关性、原创材料、互动、持续聚焦、发布时间可作观察维度；课程“1w—50w”“100赞”“30篇”等仅是历史经验与筛选线索，不是平台阈值或效果承诺。曝光低或咨询少先列有证据的假设，再在可比条件下测试一个变量；不承诺固定发布量、投流或观察天数必然见效。
