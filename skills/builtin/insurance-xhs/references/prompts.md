# 配套短提示词

以下为按V3方法重新编写的可复制指令，非课件截图逐字转录。skill执行时自动遵守方法，不要求用户把每段都粘一遍。教学时先整理本人真实材料，再交AI；没有的项目可空着，不编。

## 搜索卡位词

```text
我的服务人群是【】，熟悉的保障问题是【】。根据这些客户问法【】和搜索截图【】，整理“客户会搜的词 / 我选的搜索词”两列，最后选10个适合持续回答的中下游词。只把截图里实际看到的词写成已观察词；你补充的标候选，不编搜索量或排名。不要按疾病、健康异常或高龄标签推荐投保。
```

## 拆一个对标账号

```text
这个账号（账号链接），帮我用这个表（截图）的思路进行拆解
```

提供V3第37或42页五行表截图，保留“它写给谁 / 它讲哪件事、卡哪个词 / 它是谁 / 凭什么让人信 / 怎么引导人咨询”和“我能搬的一招”。账号访问失败就按截图拆可见内容，别补编正文、评论或成交。

## 定位和简介

```text
根据我写的材料【】，整理“我帮谁 / 我讲哪件事、想卡哪个词 / 我是谁 / 他凭什么信我”四行定位，再写一版像本人自我介绍的简介。检查身份标签、服务对象与内容方向、真实经历、做事方式四个模块，不限定实际四行，不硬塞咨询入口；没有依据的经历、数字和身份不要补。再简短说明置顶和近期内容怎么与简介保持一致。
```

## 用素材生成10个选题

```text
这是我的定位和素材表【】。围绕同一条保障主线，生成10个我有材料能讲清的选题。分别说明客户在问什么、我能用哪条真实素材、适合六种骨架中的哪一种。没有素材的标候选；别编客户案例、热度、效果数字或具体产品结论。选题来自客户原话、搜索需求、手上材料、政策产品变化，不只换标题同义词。
```

## 写图文或口播

```text
用这个选题【】和我提供的真实材料【】，写一篇【小红书图文／口播稿】。参考我本人的表达【有就提供，没有可空着】。先选适合材料的骨架，再按“代入开场—痛点放大—方案提出—解释顾虑—行动指令”检查全文，不硬凑五段。标题说出读者的具体困惑或有依据的差别，搜索词自然融入；开头马上增加信息，不重述标题或先报目录。正文先给能回答的答案，讲出理由和条件，不能只让读者去看条款。保留真实的判断和做事方式，不靠热词、排比、口头禅装人味。结尾给一个相关、能兑现的动作。不要编亲历、客户对白、数字和产品政策结论，不凭健康或年龄标签推荐投保。默认交一版标题和完整成稿，缺关键依据另列短备注。
```

## 人感改稿：有情绪、有观点

```text
把这篇稿子【】改成有情绪、有观点的小红书【图文／口播】。让人看见我在意什么、赞成或不赞成什么、为什么，保留已有表达的力度。情绪要落在具体纠结和细节上，观点要有理由；不要只剩综合考虑、建议关注。不编经历、客户对白或已发生的心理，不用疾病恐惧和投保承诺制造吸引力；新拟的个人态度如未确认，稿外简短说明供本人确认。标题点中问题，开头马上增加信息，后文顺着讲清；仍按课上五步法检查，不硬凑五段。直接交完整改稿。
```

具体按[情绪与观点](emotion-and-opinion.md)执行。

## 改标题、改前三秒

“前三秒”沿用课堂任务叫法，不表示固定时长或平台算法要求。执行标题任务按[标题统一写法](title-writing.md)，执行故事、人话与开头任务按[故事与人话](story-and-voice.md)及[开头表达](opening-craft.md)；不为吸引力补亲历、情绪或承诺。

```text
标题我觉得不够小红书吸引力不足
```

```text
前三秒的开头文案，我觉得吸引力不足帮我优化
```

沿V3第84页短句使用。优化时保留核心问题和真实依据，不为吸引力补身份、恐慌、数字或承诺；标题变化后核对正文仍能兑现。

### 标题连续不满意：用样本校准后再写

下列为2026-11-22按用户实际反馈补充的创作提示词，不冒充课件原文。执行细节见[标题统一写法](title-writing.md)中的对应小节。

```text
为我的保险经纪人账号写【重疾险】小红书图文标题。可用素材、正文与对标样本优先使用本聊天和工作台已有材料，不重复让我填表。

先校准，再写：从已实际读过的同主题图文里，找出不同的点击理由。联合看标题、封面和正文兑现，分清消费者求助、亲历分享和经纪人专业表达。学习它让人想继续了解哪件事，不借用作者身份、病例、报价、理赔结果或匿名背书。旧样本不能说成当前爆文，互动高不能证明写法有效。

从材料中找最值得提前说的具体发现、选择或进展。标题让人能认出对象、疑问或冲突；不要只把“预算、取舍、按需选择”改写成态度金句，不批量套“先别急、到底少什么、每项都想加”。不要把解决办法全部藏起来，也不要为说明严谨把标题写成合同目录。

内部比较不同内容入口，淘汰泛泛选购建议、同义换句、假亲历和证据撑不住的强结论。保留口语、情绪与有依据的力度。经纪人以自己的角色回答问题，不假扮求助消费者。

只给5条确有不同点击理由的标题，推荐1条；默认尽量20字以内，自然表达优先。单独用一句话指出最关键的素材条件；没有材料就写一般解释题，不编出案例。不要附正文、评分或效果承诺。
```

用户反馈“不够小红书”时，按[开头表达](opening-craft.md)指出原稿的具体问题，给有实质差异且素材支持的开头，推荐一版并顺接正文。不把题目改成问句就当作优化，不用“你会怎么做”连续设问拖延有效信息。这是日常改稿补充，不冒充课件原文。

同时要求标题、开头和正文整体优化时用：

```text
这篇稿子【】读起来太像讲义。请指出一两处具体问题，直接改成完整的小红书【图文／口播】。标题写具体困惑，开头不重复标题，正文把答案和理由讲出来；保留我有依据的立场、真实细节和必要条件。不要只加“姐妹们、听劝、建议收藏”，不要虚构故事，不要只交几个开头让我选。附一句说明最主要改了哪里。
```

## 原题延展9条

```text
保留原题【】，再延展9条，共10条。每次只换一处，如客户问法、就医场景、比较条件或资料角度；仍围绕同一人群和保障问题。列出这次变了什么、需要哪条真实材料，不只是换同义词，不把候选说成验证过的爆款。
```

## 课堂使用

V3的五项主要练习依次是搜索词、拆1个账号、定位和简介、素材生成选题、AI创作笔记。每项整理成果发课程群；写稿先互评与自查，报备后再对外发布。延展练习可放在成稿和点评之后，不因为旧页残留的任务编号强行加任务。数量与课时按用户当前安排，用户只要某一步时直接完成该步。

发布提醒原句：“请先报备，再发表笔记。报备路径：明亚APP-我的-自助服务-发文报备”。具体KOS／非KOS差异沿已确认的现行要求，无资料不编。
