# 可选提示词与课堂带练

这些模板用于用户需要自行操作AI或教学时；skill执行时自行遵守，不要求用户逐次粘贴。

## 写稿输入模板

```text
帮我写一篇保险小红书笔记/口播。
已确认的身份与服务范围：【可留空，不得补造】
目标读者与处境：【谁正卡在哪】
本篇阅读任务：【弄懂一个问题/做比较/看条款/算账/其他；大方向请先明确任务】
我的判断及理由：【真实观点；没有则先给一般科普角度】
可用素材：【客户问法、真实经历、官方资料，标明来源和可公开范围】
本篇希望读者做什么：【可留空，按内容选择可兑现动作】
风格参考：【本人原文或偏好，可留空】

先检查切口和素材是否支撑结论；缺少关键事实时问一个必要问题，或交明确的工作草稿。不得编身份、客户经历、案例、效果数字、政策和热度。正文体现判断依据，结尾不收集公开健康资料。按包内human-speech.md检查：明确阅读任务、先场景后概念、必要术语当场解释、删无关旁支、结尾动作可执行。按evidence-and-value.md检查：关键主张有对应依据，真正兑现标题，不只提醒“去看条款”。比较文可有多个必要维度，不能凭空编产品差异。默认只交成稿，不附检查报告。
```

## 按问题选结构

- 清单：需要整理资料或比较条件时使用，各项确有不同作用，不为凑数补项。
- 方案：需要行动顺序时，写清起点、关键条件、步骤与何时需要正式核查。
- 观点：有明确判断与证据时，说明通常认知在哪里失效、什么情况下仍成立，不强制反常识。
- 单问单答：一个误解即可讲清时，直接回答，再解释条件和下一步。

## 改稿追问：按实际问题选择

- “把这篇从大方向收窄到读者正在做的一个选择，不增加未经提供的经历。”
- “这里有什么判断依据？保留可核实内容，没依据的主张删去或单列核验问题。”
- “这里太空，优先用我给过的细节解释；没有素材请标出需要补什么，不编案例。”
- “保留我的表达习惯，删掉重复说理与泛泛劝告，不强行全改成短句。”
- “这个结尾是否真的接得住？没有已确认的服务就改成相关自查，不承诺资料或公开收集病史。”

不要把所有产品名和数字机械删除：核实且允许使用的可以保留；未经证实且影响结论的不得留进候选发布稿。

需要算例时，明确说明是假设，先列计算条件，再给过程和结果；有配图时把关键条件一起放进图里。数字只是解释工具，不得冒充真实产品、客户案例或已发生理赔。

## 内容初审模板

输出：问题原句 / 问题类型 / 影响 / 建议改法 / 依据及核验状态。
检查事实、语境、身份及授权、适用条件、隐私、引导动作；不只检查敏感词。不把“替换后的句子”视作已获机构审核。

## 课堂带练示例：50分钟，可随课时调整

| 时间 | 任务 | 产物 |
|---|---|---|
| 10分钟 | 从大方向切一个具体问题 | 内容卡 |
| 5分钟 | 整理身份、判断和已有证据 | 可用素材与缺口 |
| 15分钟 | 选适合的结构出初稿 | 第一稿 |
| 15分钟 | 检查作者判断、事实及结尾，人工修改 | 第二稿与核验项 |
| 5分钟 | 同伴指出最不清楚的一处 | 下一次修改动作 |

课堂交付是练习稿，不默认等同已获批准的对外稿件。互评不使用真实客户敏感资料。
