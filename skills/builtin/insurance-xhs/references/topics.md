# 搜索卡位与连续选题

依据V3第19—32、63—67页；围绕同一人群和保障问题持续讲。搜索研究得到需求线索，不等于可承保或可赔付结论。

## 从客户问法，走到卡位词

1. 先定自己能服务的人和熟悉的保障问题，从真实咨询、评论、搜索下拉及结果页找问法。
2. 区分上游大词、中游具体需求、下游具体问句。例如“医疗险→医疗险医院范围→医疗险的医院范围包括特需部吗”。优先研究与能力匹配的中下游问题，不只抢大词。
3. 有访问条件时，记录查询日期、输入词、下拉或相关搜索、结果页样本与链接；对照真实意图，不把同义词简单堆成词库。
4. 看词的需求线索、结果内容质量、评论问题，以及自己有没有材料写出有用答案。课程“话题1w—50w、TOP10赞藏较少”仅作历史筛选经验，不是平台公布标准，不证明低竞争或稳定获客。
5. 课堂搜索表只保留“客户会搜的词 / 我选的搜索词”两列，最后选10个。检索时间和证据另作简短备注，不给表格另造必填列。

无法实时检索时用真实问法形成“候选词，未做实时验证”，不能编搜索量、排名、下拉或平台热度。疾病、高龄问句仅能用于解释年龄、健康告知、核保和既往症等核查条件，不写推荐或替代投保路径。

卡位词自然融入标题、相关正文与标签，不强制放在标题前半句，也不为放词牺牲日常表达。不是重复次数越多越好，要让整篇真的回答搜索问题；无依据不承诺收录、排名或曝光。

## 一个方向怎样连续写

选题来源四类：客户原话、搜索需求、手上材料、政策与产品变化。素材四类：问题记录、正式资料、工作过程、本人经历。先看有哪份材料，再决定今天能讲清哪个题。

延展10条时，保留原题再生成9条，每次只换一个地方，例如使用场景、具体问法、比较条件、资料角度或说明方式；不要只换同义词，仍回答同一个问题。每条说明变化、回答方向及需要的素材，信息不足的列候选，不包装成已验证爆款。

以下是方法示例，未验证热度，不是原帖标题或产品结论：

| 选题 | 本次变化与材料 |
|---|---|
| 原题：已有百万医疗，想去特需部先看什么？ | 原问题；对应医院范围原文 |
| 医院写进合同，就代表所有科室都适用吗？ | 换问法；医院与科室约定 |
| 门诊去得多，医院范围之外还要核什么？ | 换就医场景；相关门诊责任 |
| 对照两份医疗险，医院范围怎么放在一起看？ | 换对照方式；同版本正式材料 |
| 把就医需求列出来，保单从哪里看起？ | 换工作过程；可公开的空白对照表 |

不是每条都必须有亲历；解释类依靠正式资料，服务实录和情绪故事则必须有真实过程或本人经历。

## 筛掉暂时写不了的题

判断：是不是目标人群真会问？能否一篇说清？是否有相应资料？有没有与已有内容不同的信息？能否自然体现作者判断？违反风控或依赖虚构身份的直接去掉。

规划账号先讲深一个保障方向，不把课程“最有收益的产品”改写成佣金优先或投资收益导向。也不把“持续30篇”等经验数当篇数任务；根据可用材料、用户要求和实际反馈安排。
