# 证据与实用性检查

让读者读完能弄懂、比较、判断或行动；人感负责降低理解成本，证据和具体解释负责支撑内容。不要把“写得短”“只讲一点”与“值得收藏”画等号。

## 按任务决定交付形态

| 阅读任务 | 有用的交付 | 常见空缺 |
|---|---|---|
| 弄懂一个问题 | 直接回答、解释原因、指出必要条件 | 只说“要看情况” |
| 对照选择 | 一致的比较维度、可核实差异、选择条件 | 挨个介绍却不说明怎样取舍 |
| 看懂条款 | 对应原文、位置、日常话解释、适用边界 | 只提醒“翻合同看看” |
| 算清一笔账 | 输入条件、计算步骤、适用范围 | 只报省钱或赔付结果 |
| 整理办理流程 | 官方入口、地区与时间、顺序、所需材料 | 全国套用时限、入口未核 |
| 经历或观点 | 真实素材或明确示意、具体细节、有理由的判断 | 编亲历、只有态度或金句 |

清单、图、表、算例只是可选载体，不是篇篇必备。基础科普允许没有产品对照，但标题不能承诺“实测”“逐条核对”“看完就会选”而正文没有完成。

## 采集笔记如何使用

把采集原文、截图、字幕、教学分析分清。它们可以证明某作者如何表达，不自动证明产品、法规或个人经历的真实性。

对标时记录：样本链接或本地证据 / 采集日期 / 阅读任务 / 标题承诺 / 信息组织 / 证据呈现 / 可带走的东西 / 结尾动作。没有正文或完整口播时不冒充已读全文。

互动数据注明采集时点与口径。库里既有高互动样本，也可能有普通稿，不统一叫爆文。不从收藏数直接推出收藏率，不由互动推断咨询、成交、投流来源或因果。

多知识点的高互动图文可以借鉴一致维度和视觉关系，不因此证明“越多越好”。吸收标题中的具体疑问和差异，不复制恐吓、夸大、无依据比例、规避规则写法或未确认的资料领取承诺。

## 条款对照的证据要求

确认产品、计划、版本、保障期间与相关文件是否对应。需要时同时查主险、附加险、特别约定、健康告知和正式投保规则；不要以一张营销页代替全部依据。

建议用以下工作表整理，按篇目裁剪：

| 原文与定位 | 这句话说什么 | 哪些条件或例外 | 对读者问题有什么影响 |
|---|---|---|---|
| 文件名、版本、页码/章节及短摘录 | 用日常话解释 | 期限、责任、对象等 | 说明能判断什么、尚不能判断什么 |

每项差异应有对应证据。某一责任不保证续保，不可扩大成整份保单都不保证；合同写了保证续保，也不能推定全部附加责任一律同期限。

证据齐全时，可制作逐项解读或对照；只有采集笔记时，先核正式文件。无法核实时可问用户提供对应公开资料，或交一般说明/带独立缺口备注的工作草稿，不凭印象写成实证稿。

不要把演示句式放进表格后冒充条款原文。模拟措辞和数字须标明仅为说明，不能给模拟产品安真实名称。

## 数字、算例与配图

没有个案资料时，可用明确标识的简化假设解释计算机制，不因此假装掌握真实产品事实。不要把抽象科普一律改成算账；只有数字能帮助读者完成本篇任务时才使用。

计算前说明影响结论的假设：费用中哪些符合范围、尚余多少免赔额、适用比例、额度是否充足及有无其他扣减。金额、比例和合同处理顺序不能默认通用于全部保单。

校对原始数字、单位、公式、四舍五入和结果；若对照两种情况，明确改变了什么条件。公式可能给出负数时应说明不产生负赔付，不能机械照算；不为了突出差距挑选或隐藏条件。

对照表或图卡是内容的一部分。关键的“假设算例”标识、条件和限定要能随图一起被读到，不能只放在作者备注。图内结论与正文一致，示意图不伪装成真实结算或理赔文件。

实际示例见 [本轮试写](worked-example.md)。它提供表达方法，不构成任何具体保单的理赔承诺。

## 交稿前的三个问题

1. **具体讲清了什么？** 是读者可能不懂的区别、判断条件或行动方法，还是把常识重新说了一遍？不强求独家内幕。
2. **依据在哪里？** 主张、证据和适用范围是否对应？没有产品材料时，是否避免了确定的产品对照？
3. **读者带走什么？** 能否用自己的话解释区别、按步骤完成检查，或知道哪一个条件影响选择？

若标题承诺具体解读，正文却只剩“问清楚”“看合同”“因人而异”，应补相应解释或降低标题承诺。不能用口语改写和更刺激的标题掩盖资料不足。

## 对本轮医疗险试写的修正

“报过一次明年还能不能续”可作基础问答；但完整解读要说明合同中的保证续保期间、期间内的规则、期满规则分别回答什么，并在真实材料齐全时展示对应位置。

“不同责任是否同期限”更具体，但须核实产品及主附险文件后再下结论。不能因为采集到《20年保证续保，救命药可能只保1年》的标题，就把这句话当作所有产品事实。

“医疗险类别对比”可以讲多类保障，前提是维度一致、差异准确、图文条件一致。嵌套图可能误导为责任自动包含，视觉组织也必须接受事实检查。
