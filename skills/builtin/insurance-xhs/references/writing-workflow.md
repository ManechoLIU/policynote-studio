# 按课件写：四步创作、六种骨架、五步法

依据11.19版实际第64—88页，逐段作用参照第150—151页。先使用已有定位与素材，按本次任务执行；单句润色无需重新定位。写稿同时读[小红书表达](xhs-copy-craft.md)、[人感检查](human-speech.md)和[证据与实用性](evidence-and-value.md)。

完整个人稿件同时执行[情绪与观点](emotion-and-opinion.md)：确认作者的感受、立场与依据，再组织内容；用户只要客观摘录或局部改动时按范围处理。

图文同时按[社区中的图文交流](community-image-posts.md)确认作者角色和本篇交流任务，再安排整组配图。六型用于选择组织材料的方法，五步用于检查专业解释是否充分，不把消费者求助或情绪亲历改造成经纪人教程，也不新增第七种课程骨架。

## 第一步：选题，先确定这篇要回答什么

先有客户问题，再找自己能回答的材料。四个来源是客户原话、搜索需求、手上的材料、政策与产品变化；分别查问题记录、正式资料、工作过程、本人经历。

素材卡沿用课件三行“一件你想讲的事 / 客户的原话 / 能核对的资料”。用户没有客户逐字记录就写“一般问题”或“概括问法”，不编原话；没有亲历可写一般解释，不必每篇都挖出故事。

例如“医疗险”仍太宽，可写“已有百万医疗，想了解特需部就医，先对照保单哪部分”。本篇完成医院范围解释，就不顺便把全部险种重讲一遍；若做保障分类比较，则用一致维度讲清必要差异。

## 第二步：选型，按问题和材料选一种骨架

需要故事感或真实工作过程时，先读[故事与人话](story-and-voice.md)。只有问题和资料也可以写答疑或比较，不强求真实故事；新读到的叙事技巧只补充表达，不替换下表六型和后面的五步法。

| 六种骨架 | 适合什么问题 | 正文怎么展开 | 不要照抄的部分 |
|---|---|---|---|
| 反常识观点型 | 有依据说明一种常见判断在哪些情况下不成立 | 明确判断→解释理由→承认另一种情况→给出适用标准 | 不固定“同行不爱听”，不贬损产品或同行 |
| 情绪故事型 | 有真实经过，读者需要认识作者怎样作选择 | 具体场景→当时的困难→做了什么→形成什么判断 | 不编住院、对话或身体感受；不强制每篇算账 |
| 攻略清单型 | 读者分不清几类责任、步骤或比较条件 | 说明要解决什么→用一致维度整理→解释怎样取舍→给动作 | 不凭健康和年龄分类推荐，不将类比当实际责任 |
| 热点政策型 | 有已核实、确与读者问题有关的新文件 | 发生什么→影响谁、什么条件→哪些结论不能推出→能做什么，附来源 | 不编“刚发布”，不把支付政策直接推成商业险责任改变 |
| 服务实录型 | 有本人真实服务过程或可公开的产物 | 展示产物→原问题→具体做法及依据→读者第一步 | 不抄别人“昨天花3小时”，不展示未经授权的敏感原件 |
| 避坑揭秘型 | 有明确资料支持某种遗漏或误解 | 指出具体误区→解释为什么→给对应做法→自查动作 | 不凑固定3个坑，不做产品黑榜或人群禁买榜 |

问题只需短答就短答，不为套骨架扩写；较完整的创作和拆解使用上述命名方便课堂沟通。

## 第三步：标题和封面，把问题一眼说清

先按[标题统一写法](title-writing.md)选择读者真实疑问和具体表达。以下课件角度作为补充，不替代统一标题写法；单独改标题只交标题，写整篇则内部比较后交推荐标题与正文。

同时读[开头表达](opening-craft.md)，区分标题、图文正文开头与实际口播。图文开头要推进标题里的问题；代入开场可直接给判断、具体选择或真实细节，不强制先设问再讲道理。

11.19版第87页的六种标题角度可用，下面为本版重新编写的示例，不冒充原帖：

| 角度 | 可用标题示例及前提 |
|---|---|
| 数字冲击 | 《对照两份医疗险，我会先看这3项》；正文确实解释3项，不编保费和效果数字 |
| 反常识 | 《保额相同，医疗险能报的范围也相同吗？》；有依据解释差异 |
| 人群直击 | 《刚开始了解宝宝保障，先分清这两类问题》；不作统一投保方案 |
| 故事开场 | 《从一次住院经历，到一张就医需求表》；仅限作者确有该经历 |
| 避坑警告 | 《比较医疗险，别漏了医院范围这一项》；解释具体影响，不写必买必赔 |
| 发现感叹 | 《原来名字相近，保障范围还要这样对照》；确有对应比较材料 |

主搜索词自然融入标题，不强制放在前半句；读起来生硬就调整句子，正文和标签仍围绕同一问题，不堆词。六种角度是选择，不是固定标题公式；不批量复制“先看这3项”“原来……”“别再……”的句架。封面少字、手机小图能看清；大字报适合突出判断，备忘录适合清单，真人出镜适合本人介绍或经验表达，按材料和本人意愿选，不强制露脸。标题、封面和正文共同兑现一个承诺。

## 第四步：用五步法写正文并收尾

名称保持“代入开场—痛点放大—方案提出—解释顾虑—行动指令”。每一步解决一个读者疑问，成稿可自然合并段落，不在正文硬贴教学小标题。答疑先给当前材料能支持的回答，故事按真实经过推进，清单按必要项目展开；不先给五步各填一句，再拼成同一种文章。

| 五步法 | 直白解释 | 医疗保障问题的二创句式示例 |
|---|---|---|
| 代入开场 | 先让读者知道你讲的是他眼前哪件事 | “已经有百万医疗，想去特需部时，这份保单还适用吗？” |
| 痛点放大 | 讲清卡在哪里、漏看会影响什么，别吓人 | “只看产品名字，仍不知道医院范围具体怎么约定。” |
| 方案提出 | 把判断方法和实际答案讲出来 | “先找到合同的医院范围，再对照院区、科室及相关责任约定。”真实解读应接上对应原文、位置和解释，不能到此结束 |
| 解释顾虑 | 回答读者会追问的条件和例外 | “写了某类医院，也要看是不是这项责任的适用范围，不能只凭医院名字下结论。”具体稿依据对应材料说明 |
| 行动指令 | 给读者一件现在能做的事 | “把保单的医院范围和自己的就医需求列在一起，先找出还没弄清的那一项。” |

痛点是实际困惑和取舍，不是放大疾病恐惧；方案可以是解释、对照方法或办事步骤，不等于推荐购买；解释顾虑不代表消除全部风险。行动可以是自查、查官方材料或一般讨论，不强制私信、关注、领资料。

真实求助、经历和情绪交流按其任务检查是否表达完整，不强补解决方案、行动指令或积极结局。拆解中缺少的步骤如实记录；专业答疑则不能用开放讨论省去本该给出的答案。

只有确认服务能力和机构、平台可用渠道后，才说明能进一步帮到哪一步。评论区和普通平台私信不索取病史、证件、完整保单等敏感资料。

## 拆案例时，五步名称不变

每步名称后用一句人话解释；每块只留两三句，包含原帖具体句段、为什么这样写、怎么模仿的短句式。选一句真正该记住的话标红，其他正文保持正常颜色；格式不支持红色时用加粗并注明建议标红。

原帖缺哪一步就写“原帖未展开这一点”，不要把推测补成原文。另写“二创补充建议”，再给可用写法。二创标题说明从哪个具体问题进入；二创写法给开头、正文、结尾示例。

社群展示依次为“① 原帖封面与配图”“② 原帖正文”“③ 结构拆解与二创”，三行后不加抓取或删改说明。原帖完整保留、保留来源链接；只拿到节选时说明材料不足，不冒充全文，不拿课件节选反向补造原帖。自己的拆解、标题和二创执行[项目风控](content-risk-rules.md)。

## 写完后检查

先核事实与条件，再检查作者的情绪和观点是否能被读者感知，然后改语言。标题的问题是否真的回答了？读者能否理解为什么这样判断？六型与材料匹配吗？五步有没有缺了必要解释？结尾能否兑现？

核对[证据与实用性](evidence-and-value.md)中的原文位置、测算假设和图文一致性，再按[人感检查](human-speech.md)删空话和无关术语。缺决定结论的证据则交工作草稿，独立列缺口，不能把“具体看合同”当已完成解读。

优化标题只改标题吸引力；优化前三秒只改开场并顺接正文，不加新事实。用户只要成稿就交标题和正文，有重要缺口再加短备注，不附一大套内部评分。


需要依据最新课件给学员选结构、改完整稿时，参照[学员写稿与改稿](student-writing.md)；需要原帖依据与反例时，参照[分类样本](research-patterns.md)。局部标题或单句任务仍只处理指定范围。
