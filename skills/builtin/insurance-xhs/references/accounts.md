# 找对标与拆账号

依据V3第34—43页。先看对方是不是在回答同一类客户问题，再看哪种表达自己能做到；不按粉丝量单独判定值得学。

## 怎么找

搜索已选的细分问题词，可分别看高点赞和高评论样本，再进入账号看持续更新、主线、人群、评论中的具体提问以及形式是否可模仿。课程“各看20个账号”“有100赞爆文”是找样本的练习线索，不是平台门槛；按实际任务范围收集即可。

点赞可能说明吸引兴趣，评论中的具体提问可提供需求线索，但不证明后台咨询、成交或获客能力。记录账号链接、查询时间、实际阅读范围；主页自述、可见事实与分析判断分开。

## 沿用课件五行＋一招

| 填什么 | 看哪里、怎样判断 |
|---|---|
| 它写给谁 | 从标题、简介和问题看具体的人及处境，不只写“宝妈” |
| 它讲哪件事、卡哪个词 | 主页大部分笔记围绕什么，标题和标签反复出现什么词 |
| 它是谁 | 简介除了保险职业还展示了什么真实标签；注明为其自述 |
| 凭什么让人信 | 指出具体身份、经历、资料或工作过程及对应位置，不只写“专业” |
| 怎么引导人咨询 | 结尾、主页及评论怎样回复，读者具体在问什么；观察不等于赞同其渠道和承诺 |
| 我能搬的一招 | 指出一个可复用办法，换成自己的问题写一个标题；不搬身份和经历 |

主线用“被搜到→被相信→被找到”；课件表第五行保留原字段“怎么引导人咨询”，其中“被选择”是观察读者为何愿意问的角度，不另造一套账号流程。

只能访问主页截图时就拆可见信息，缺正文或评论写明缺材料。账号链接打不开可用用户提供的截图继续分析，不编当前数据。课堂只拆1个，通常20分钟，不把“拆多个账号”的页标题误作必须拆多个的作业。

## 课件中的表达样本

- 梁小保：收窄到父母保障问题，观察怎样持续拆问法；不复制年龄推荐与红黑榜。
- 索菲亚的百保箱：看怎样用图解整理复杂关系；图示不能被当成责任自动包含的事实。
- 小蔡碎碎念：看怎样把客户问题说成日常话；不抄客户对白和“有问必答”承诺。
- 力力的保险日记：看经历如何解释内容方向；不把其就医经历写给学员。

这些是用户课件中的教学样本，未在本版独立核验当前主页、后台数据或服务结果。不把同名账号当同一个人，不称已验证成功名单。

单篇拆解继续按[写作流程](writing-workflow.md)的六种骨架和五步法，原文与二创分开；[项目风控](content-risk-rules.md)决定原帖展示和二创边界。
