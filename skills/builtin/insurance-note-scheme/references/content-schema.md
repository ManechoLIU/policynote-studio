# content.json 结构

`scheme.py build` 的唯一输入。一次写完全部方案，由脚本落盘为 `方案X/方案.md`、`方案X/溯源.md`、`assets/covers/cover.json`，再渲染封面并跑门禁。

```json
{
  "brief": {
    "mode": "4 套比较",
    "topic": "重疾险等待期三个日期",
    "must": "用户点名必须包含的信息",
    "reader": "刚拿到方案的父母",
    "reader_assumed": true,
    "scene": "小红书搜索",
    "tone": "克制",
    "product": "未指定，按通用重疾险写、不点名",
    "boundary": "不承诺赔付、不写统一数字",
    "question": "读者此刻在问的那一句话",
    "assumptions": ["无指定产品，按通用重疾险写、不点名", "读者按正在考虑投保处理"]
  },
  "variants": [
    {
      "letter": "A",
      "angle": "这套与另外三套的区别，一句话",
      "title": "≤20 字，说清具体疑问或差别",
      "reader": "谁的什么处境",
      "next": "读者读完下一步做什么",
      "body": "300–700 字正文；待核事实用【待核实】标出",
      "open": "本篇没有回答的问题，可留空",
      "cover": {
        "layout": "a",
        "letter": "A",
        "kicker": "重疾险 · 等待期",
        "title": ["等待期不是", "90 天这么简单"],
        "lede": "同样是 90 天，起算点不一样",
        "rows": [["适用", "刚拿到方案的父母"], ["依据", "条款写的起算日"], ["不适用", "已过等待期"]],
        "band": ["本篇回答", "先看起算日，再比较天数"],
        "footer": ["账号名", "内容为个人理解，具体以条款为准"]
      },
      "sources": {
        "title": ["6a17f946…《到底要不要给婴儿重疾险？》 https://…", "用问句提出具体困惑", "不借新手身份"],
        "cover": ["无直接对标：按模板构图", "先给判断再补条件", "不搬原图"],
        "body": ["无直接对标：按写作流程生成", "先结论后边界", "不抄原句"]
      },
      "facts": [
        ["等待期起算日以条款为准", "规则", "产品条款", "在售版本", "已核", "条款更新"],
        ["等待期常见 90 或 180 天", "数字", "待补条款", "—", "待核", "—"]
      ]
    }
  ]
}
```

## 字段规则

- `brief`：可选；给了 build 就写 `需求单.md`。`mode` 写“4 套比较”或“1 篇成稿”，`reader_assumed` 为 true 时需求单标“假设”。
- `letter`：A–F，唯一；单篇只写一个。
- `title`：≤20 字（去空白计）；超过 build 直接拒绝。
- `body`：200–1000 字（build 硬门槛），建议 300–700；四套合计 ≤3000。
- `cover`：四种 layout 之一，字段与该 layout 对应；`a` 用 title/lede/rows，`b` 用 title/table，`c` 用 title/items，`d` 用 title 对象/note/rows。`footer` 两段。
- `sources`：`title`/`cover`/`body` 各三项 `[参考案例ID+链接, 借鉴点, 不复用什么]`；没有对标写“无直接对标：按方法层《…》生成”。
- `facts`：每条六列 `[主张, 类型, 依据/来源, 版本或口径, 状态, 失效时间]`；状态只能已核/待核/不适用。待核项正文必须出现 `【待核实】`。
- `open`：可留空。

## 写多个方案

`variants` 数组重复 A 的结构，改 `letter`、`title`、`cover.layout`（四套不重复）、`sources`、`facts`。不要复制同一套正文改标题。

## 常见拒绝原因

- 标题超 20 字、正文不足 200 或超 1000；
- `cover.layout` 不是 a/b/c/d；
- `sources` 缺三行，或 facts 为空；
- cover 文案仍带 `【】` 占位（build 不拦，check 会 FAIL）。
