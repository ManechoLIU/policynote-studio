# PolicyNote Studio

面向保险内容创作者的本地工作台，连接内容策划、账号画像、保险内容技能、图文制作与复盘入口。Policy 呼应保险，Note 呼应笔记创作。

基于 [寻欢小红书工作台](https://github.com/huansun608-ship-it/xunhuan-xhs-workbench) 继续定制，原始项目为 [ZJU-REAL/Easel](https://github.com/ZJU-REAL/Easel)。

## 当前范围

- 保留 Easel 的本地 Web 工作台与技能系统。
- 工作台名称及界面配色已定制；保险内容优先路由已配置。
- 保险技能安装快照为v1.4.0，不能将另行整理的v1.4.1资料误认为已完成升级。
- 教学目标围绕被看见、被相信、被选择；学员专用流程与多用户权限仍需后续开发。

本仓库公开可复用源码与技能，不包含本机密钥、登录态、学生画像、学员作业、客户资料、采集数据、课件和内容产物。私有资料包应单独保管，按授权在本地接入。未承诺流量、获客结果或保证合规。

当前为开发中的源码快照。账号登录、数据源接入和平台草稿等真实集成仍在完善，代码上传不代表这些流程已完成验收。

### 小红书草稿的已知限制（2026-11-04）

- 小红书网页草稿保存在工作台专用浏览器本地；手机 App 与官方网页共用云草稿不在当前方案支持范围。
- 验证时曾看到本地草稿条目及占位封面截图；完整图文在浏览器重启后的重新读取、稳定成功回执，以及使用同一浏览器配置查看草稿的入口仍未完成。
- 当前验证环境仍有小红书官网 TLS 连接失败及创作者页面白屏，官网访问与原文页面跳转尚未恢复验收。本版修正草稿范围说明，不代表这些问题已解决。

## 安装与使用

原版安装步骤及依赖见 [Easel上游说明](README_UPSTREAM.md)。需要Python 3.10+、相应Agent执行引擎及按需配置的媒体服务；自行配置 `.env`，不得提交真实密钥。Windows可参考 `setup.ps1`，安装完成后使用 `启动Easel.ps1` 在127.0.0.1:7860启动本机服务。

公共源码副本没有打包虚拟环境、Node依赖与个人配置；克隆后需要安装依赖。所有账号授权、AI服务配置及发布动作应在使用者自己的环境完成。
