# 明亚工作台浏览器连接

每位使用者在自己的日常 Chrome 个人配置中安装本扩展（Chrome 118 及以上）。在 Chrome 扩展管理页启用开发者模式，选择“加载已解压的扩展程序”，选择本目录，安装时按 Chrome 提示授予必需的调试器权限。打开扩展，输入自己的工作台 HTTPS 来源；仅本机回环地址允许 HTTP。点击连接并在浏览器提示中授权该工作台来源，然后刷新工作台页面。扩展绑定不代表小红书已登录。

扩展只对用户明确绑定的工作台生效；保存动作需在工作台确认。草稿在该浏览器个人配置的本地草稿箱中查看，不保证同步到手机。若保存结果未确认，先检查草稿箱，不要重复提交。扩展不读取其他浏览器配置或导出登录凭据。

正常保存草稿无需重新加载扩展。首次安装和连接完成后，可在同一浏览器持续使用；手动更新本目录代码时，在扩展管理页重新加载一次即可。
